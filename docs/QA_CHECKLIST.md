## ✅ 1. 핵심 유저 플로우 검증 (PRD 1장, 3장)

- [x] **단일 화면 원페이지 완결 경험**
  - [x] 사진 첨부 → 조미료 선택 → 요약 버튼 클릭 후 화면 전환 없이 결과 영역으로 스무스 스크롤 이동되는지 확인
  - [x] 페이지 새로고침이나 URL 변경 없이 전체 추천 과정 완료 확인
- [x] **결과 영역 렌더링**
  - [x] 추천 레시피 카드가 1~3개 노출되는지 확인
  - [x] 각 카드 상단에 난이도, 소요시간(분), 칼로리(kcal) 정보 표시 확인
  - [x] 넘버링된 조리 순서 텍스트 리스트 정상 노출 확인

- [x] **AI 응답 실패 및 회복 (PRD 5-5)**
